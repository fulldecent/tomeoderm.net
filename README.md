# tomeoderm.net

This project is built based on [best practices documented in github-pages-template](https://github.com/fulldecent/github-pages-template), commit 7f01f52a68a7480c4df8841be7fc2614d60ca930. The lint workflow is that commit's .github/workflows/lint.yml. Jekyll build scripts from the template are omitted. Prettier's liquid HTML parser does not reach a fixed point on `index.html`, so `.prettierignore` lists those files.
